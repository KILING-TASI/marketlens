# 原文核对：附件、指标关联与限定条件

以下字段都可选，旧的 source-review/1 和 source-review/2 输入仍可使用。未知内容留空，不补造来源、页码或关联。

## 把指标关联到具体问题

在输入顶层添加 `metricBindings`。每项包含 `claimId`、`metricId`、`rationale`，分别引用已登记的主张、公告指标及关联依据。关联由输入者声明，程序不认证它的经济含义。

```json
{"metricBindings": [{"claimId": "claim-1", "metricId": "profit-1", "rationale": "该主张讨论这一报告期的净利润，先核清合并口径"}]}
```

`sources compare` 会沿旧、新两轮的明确关联提示数值、口径、来源及关联删除的影响。没有关联时只提示指标记录变化，不猜测哪条主张依赖它。比较不覆盖或重算旧报告。

## 登记必需附件

来源项的 `requiredAttachments` 是其他资料 ID 的列表，未取得的附件 ID 可以先保留。例如正文声明 `["attachment-1"]`。附件取得后，要在 `sources` 登记其文件，并在 `sourceRelations` 登记 `from: attachment-1`、`to: 正文ID`、`type: attachment` 和理由。

只有登记关系、文件能读取、有非空提取文本且提供的摘要没有冲突时，才列为“已登记且读取”。必需附件缺失时逐项意见保留待核。附件改版会沿已登记关系提示正文相关主张复查。这些检查不认证附件的真伪、完整性和表格含义；空白扫描页也不能当作已经核完。

## 定位公告数字与表格脚注

公告指标可填写 `evidencePage`（从1开始的 PDF 提取页码）和 `evidenceExcerpt`（逐字原句）。未填指标页码时沿用来源页码；未设任何页码时查找全部提取页。报告保留页码、文本偏移及前后文，以便核对单位、表头、脚注和更正。

数字与单位命中只是一条线索，来源检查失败会另行告警。PDF 不做 OCR，提取顺序不代表表格行列关系；`tableLayoutVerified` 保持 false，附件不自动扫描发现。扫描件、复杂表格、多列阅读顺序仍需查看原 PDF。基础安装没有 PDF 依赖；确需处理 PDF 时安装 `marketlens[pdf]`。

## 避免截取原句改变含义

支持意见周边出现否定、前提条件，或引文含主体/事项指代时，程序会保留原意见并将有效意见标为待核。需要拆开主体、动作、阶段和否定范围，再补清晰原句与依据。

这是一组有限措辞规则，可能误报、漏报，尤其是相邻的无关句子、反讽和多重否定。当前不提供指代自动解析，不自动把“不是没有”“不排除”判断为执行事实，也不把保守提示当作消息为假。为解除歧义，应提供更明确的直接披露；无法解除时保留未知。

## 网络故障与页面改版

默认核本地文件，显式 `--verify-urls` 才访问声明地址。HTTP 429、502/503/504、其他失败状态分别保留故障类别、状态码、重定向链及来源返回的 Retry-After；它只是网站声明，不是精确恢复承诺。不会自动重试或绕过限流。超时或不可访问也保留失败原因。

同一地址的实际下载字节变化时提示不一致，不能认定本地文件伪造或选择哪版正确。分别保存文件与披露时间，登记更正关系，再比较两轮冻结结果。

这些处理不认证网站运营者或消息真实性，不扩大第三方文件和数据的使用权。
