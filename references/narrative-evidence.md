# 叙事与证据

先识别问题是证据可信度、交易解释、执行进展或当时是否可知。把“国家队撤退、融资接盘、牛市确认”拆成独立主张，不以整体语气判断真伪。

每个重要主张关联主体、动作、证券/业务范围、发生期间、披露时间、金额口径、原句、来源与核验状态。用户数字可用于情景运算；未核验的现实数字称为“按你提供的资料”。假设测试无需联网认证虚构设定。现实问题引用特定网页或政策而未获原文时，用可用工具取得原文；失败则保留转述范围，不编造核验。

证据：E0无身份线索；E1间接/转述；E2计划、承诺或融资安排；E3已执行披露；E4持仓披露。E4不比E3更能证明交易细节。官方承诺只确认承诺，额度、操作、融资与买入分别核查。

“已增持部分ETF”不支持“某日买入510300十亿元”，证券、日期和金额都需独立依据。执行原文到达时可确认其明确范围，即使行情常态。匿名持有人不能从规模匹配汇金，机构占比不证明稳市资金。业务阶段分研发、意向/合作、签约/订单、交付、收入、利润；否认某合作不否认全部业务，未披露收入不等于零。

| 叙事 | 可判断 | 不足以支持 |
|---|---|---|
| ETF放量、价格没跌 | 异常模式待解释 | 国家队买入、操纵、买入金额 |
| ETF份额减少、融资增加 | 同期活动分歧 | 国家队退出、散户接盘、两者净额 |
| 持仓市值下降 | 分解数量与价格 | 同额减持、现金回笼或观望 |
| 回购上限20亿元 | 计划区间和期限 | 已买20亿元、现金充足 |
| 多份累计回购报告 | 同事件差额更新 | 累计金额多次相加 |
| 退市企业多数有非标 | 失败样本特征 | 非标企业多数退市 |
| 最后成功重组收益高 | 事后条件样本 | 预案时可得的策略收益 |
| 地量后历史胜率高 | 核查选样和独立案例 | 事后最低日是实时底部 |
| 净值与海外时间错配 | 有效时间、币种差异 | 实时折溢价和确定套利 |

昨日截止排除今日才公开的披露。复现原确认状态还需当时已审核；重建当时公开信息可事后核验早已公开的原文，但注明事后核验，不等于恢复原决策。公开、下载、核验各有时刻。更正/终止更新事件状态，不抹去历史版本；只有正式更正引用能替代指定旧值，不能用负差额编造卖出。日期未知不猜。法规则按有效版本；公开资料不恢复强平、雪球敲入或真实账户。

结构化检查输入：`as_of`、可选`scenario`、`claims`、`evidence`。`replay_mode`默认confirmed_state，重建公开信息用public_information。主张字段：id、type（actor_execution / holdings / plan / business）、actor、scope，可选day、action、amount_cny。证据字段：id、source_type（execution / holdings / plan / business / indirect）、actor、scope、period_start、period_end、available_at（原文公开可用）、verified_at（核验时间）、source、quote、verified布尔；stage为executed / planned / holdings / business / indirect。verified是人工声明，不是脚本认证。scope按明确相同范围匹配。未知日期留空。假设标simulation:true。正式更正可用supersedes:[旧证据ID]，仅替代同主体、范围、类型且时间更早的记录；引用或重复报道不能自行撤回旧证据。
