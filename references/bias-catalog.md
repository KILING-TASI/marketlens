# 判断偏差与核对问题

偏差标签提示检查方式，不诊断个人、机构或文化，不作为消息真伪证据。来源参见theory-sources.md。

| 常见误读 | 核对问题 | 本仓已有或新增机制 |
|---|---|---|
| 只搜支持观点的材料 | 同一对象和期间有无反对材料、竞争解释？ | 四种关系、竞争解释矩阵 |
| 知道结果后认为当时也知道 | 公开、取得、核验时间分别是什么？ | public_information与confirmed_state回放；不能恢复实际认知 |
| 多篇转载看起来是多份独立证据 | 原始文件是否同一份？是否有新增原披露？ | SHA分组，不把不同SHA当独立性证明 |
| 先后发生就解释为因果 | 是否有机制证据及其他解释？ | warrant与falsifier；不把同期指标当因果 |
| 回购上限被当成已买金额 | 是额度、计划、融资、执行还是持仓？ | 现有材料类型及对象/期间匹配 |
| 国有背景被当成兜底保证 | 谁负何种义务，依据哪个条款，哪些条件仍未知？ | 国内制度核对清单；不推断隐性担保存在 |

不采用固定“损失厌恶两倍”的参数，不用文化心理学解释每一次冲突；更不把传播阶段、物极必反或模型假设当成交易预测。
