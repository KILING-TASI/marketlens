# v0.4.0 证据流程验收

本轮针对六份体验报告中可复现的问题补强。31项单元测试、45项原有自检及9项中国场景检查通过；旧claim-evidence/1完整结果与冻结基线一致。源码Skill在独立临时目录、空缓存环境、无pip虚拟环境中运行原有流程及新增公告流程，并验证已有报告不能覆盖。宿主机器仍有其他仓库，隔离验收不声称物理移除它们。

实际下载并读取上交所公开FAQ页面，核对短摘录“股票ETF实施T+1交易。”与真实文件字节的摘要，报告仍明确原文含义和关联理由需要复核。来源：[ETF是否实施T+0交易](https://www.sse.com.cn/assortment/fund/etf/question/c/c_20240118_5734755.shtml)。该页面口径不是全部市场、全部品种及未来日期的规则认证。

可复现：显式使用sources fetch下载到新目录，sources scaffold以下载文件生成输入，然后填写该摘录与具体问题，sources review生成新报告。需要比较否认和更正时，逐项登记不同来源与关系，不能虚填核验人。

性能记录：Windows / Python 3.12，本地读取同一已下载HTML连续30次，计时范围含解析、摘要和逐字摘录核对，不含网络和报告写盘。样本大小、实际摘要、耗时在发布验收记录中留档；不把本机单样本扩成吞吐保证。不同文件可按相同流程重新计时。

桌面与390px宽度浏览器检查中文正文、亏损区间、原句和核查说明；检查时内容宽度375px，无横向溢出。已有历史报告保持冻结，新报告使用改善后的展示。

仍有限制：动态网站、登录内容或超时可能取不到；PDF需可选pypdf，只提取文本，不做OCR；实际下载、摘要一致及摘录匹配不认证发布者或消息真实性。一个公开HTML下载成功不证明所有数据源可用。AI辅助语义复核通过Skill实施，CLI没有自动认证模型或可信度评分。
