# v0.5.0 AI幻觉自我攻击记录

发布前用30项原创攻击输入对照初始草稿与修复版，另外固化12项回归测试。攻击的是声明、关系和结论，不执行原文里的指令，不访问用户隐私文件。

发现并补强：未来/早于披露的复核日期被接纳、未来/早于资料披露的检索被称已完成、把尚未交付填成支持已交付、局部否认推广全部、身份名称不对应仍写支持、关联中夹带伪认证字段、公告日期格式跨版本不一致，以及错误单位类型抛原生异常。分别保留为待核或明确拒绝。

金额仍是输入声明，新增专属摘录和显式金额提示，正文不再把填表值写成程序核验的披露值。对比结果忽略重复检查的观察时间，文件与实质核查状态变化仍保留。教学原文件固定LF字节，跨平台摘要严格匹配，不为示例放宽真实文件检查。

原有防线继续有效：未知引用、错误摘要、缺文件、无匹配引文、错误页码、巨量指数、程序标记注入及HTML注入没有被升级为来源认证。格式完美的本地假文件仍可能逐字匹配，虚构的审核人仍可作为声明记录；发布者和复核身份没有因此被认证。这是残留的认证缺口，不能声称已消除所有AI幻觉。

结果中的“accepted”只表示输入被处理，不表示消息被接受为真。修复后复核时间/否定/身份攻击返回unknown，认证字段及不可能的检索记录拒绝，未核数值有明确警告。完整本地输入结果及代码摘要保留在交付底稿；测试不提供真实市场准确率或概率。

68项单元测试、45项自检与9项中国场景，以及源码/wheel隔离验收为发布条件；GitHub最终提交的自动检查和发布资产摘要另行核验。复核范围未包括平台自然语言自动发现、完整OCR、发布者数字签名或人员身份认证。

## 2026-10-12 第二轮复查（v0.5.1）

本轮新增67项可复现检查：32项中文阶段场景、29项比较与定位回归、6项网络边界测试。共135项测试通过，另重跑30项原始自攻击、45项自检和9项中国场景。网络边界使用模拟解析、确认拒绝前不建连接，不宣称实际联网成功。

修复三个缺口：拟/计划/预计/有望/可能/或将交付、实施、完成或签约不得直接当作已执行支持；比较资料身份、版本、摘要和定位等变化，以及公告指标、来源关系、检索记录和研究计划变化；冻结记录重复ID或无效引用明确拒绝，避免覆盖与原生异常。比较不修改原结果，研究记录只提示整体复查，不编造未登记的指标与主张关联。

阶段检查仍是有限措辞规则，可能误报或漏报；同时含计划与执行的原句需拆开核对。本轮不是开放语义准确率测量，不解决人员认证、发行人身份认证、扫描件OCR或全部语义幻觉。

后续优先补强：否定范围与跨句指代的人工标注语料；PDF表格、脚注与附件的定位回归；实际来源断网、改版、限流的可控集成测试；将公告指标与主张显式关联以缩小变化影响范围；按固定规模重测耗时、内存并记录环境。暂不宣称这些已全部完成。

## v0.5.2 四项定向补强

新增44项检查，共179项单元、回归和场景测试。4项测试实际生成PDF并核对页码、脚注、空页及加密文件拒绝；CI矩阵安装可选pypdf执行该路径，基础安装仍不依赖PDF组件。10项受控HTTPS测试覆盖HTTP限流、暂时不可用、改址、回环目标拒绝、重定向次数、压缩响应和体积限制；另以复查流程验证超时、限流与改版不得升级意见。它们使用模拟网络，不声明已通过任意真实网站。

增加明确指标关联与必需附件声明；变更沿旧新关联与附件链提示复查，不重写冻结记录。证据页码约束指标逐字匹配并显示前后文，来源检查失败单独告警。跨句否定和指代只做保守提醒，不自动解析语义；已有支持声明可能因无关相邻句被降为待核，需更清晰直接证据，不能由此判假。

尚未覆盖：完整OCR和表格结构恢复、自动发现全部附件、开放域指代解析、真实发布者和复核身份认证，以及任意网站实际联网的稳定性。这些边界保留，不以测试数量代替真实性。
